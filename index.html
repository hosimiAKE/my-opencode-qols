Quality‑of‑life plugins for OpenCode OpenCode 实用插件合集

Small, focused patches that make the OpenCode desktop app nicer to live in. Every plugin is reversible, needs no admin rights, and re-installs itself after app updates.

一些让 OpenCode 桌面端更好用的小插件：安装可一键卸载还原、无需管理员权限，官方更新后自动恢复。

retarder

Scheduled send for OpenCode Desktop — messages wait until the time you pick.

OpenCode 桌面端「定时发送」：选择时刻后，发送的消息会等到该时刻再发出。

Off by default默认不生效

No time selected? The composer behaves exactly like stock OpenCode.

未选择时间时，输入框与官方行为完全一致，零干预。

Pick any moment任意时刻

5 min / 30 min / 1 h / today 12:00 / today 18:00 — or a custom date & time.

5 分钟 / 30 分钟 / 1 小时 / 今天 12:00 / 今天 18:00，也可自定义日期时间。

Per session按会话独立

A schedule only applies to the session where you set it.

定时只影响设置它的那个会话，切换会话互不干扰。

Survives updates更新不丢失

A logon daemon re-injects the plugin whenever OpenCode updates itself.

登录自启的守护进程会在官方更新后自动重新注入。

homelander

人民币计费显示 —— 会话使用中国厂商模型时，成本自动从美元换算成人民币。

Chinese providers only只对中国厂商生效

Live exchange rate实时汇率

Install安装

Windows · OpenCode Desktop V2 · Node.js 18+ · no admin rights. Windows · OpenCode 桌面端 V2 · Node.js 18+ · 无需管理员权限。

PowerShell · retarder
# clone the collection
git clone https://github.com/hosimiAKE/my-opencode-qols.git
cd my-opencode-qols/retarder

# install the plugin (then restart OpenCode Desktop)
powershell -ExecutionPolicy Bypass -File install.ps1
PowerShell · homelander
# clone the collection
git clone https://github.com/hosimiAKE/my-opencode-qols.git
cd my-opencode-qols/homelander

# install the plugin (then restart OpenCode Desktop)
powershell -ExecutionPolicy Bypass -File install.ps1
1

Install安装

The installer injects the plugin into the app and registers a logon daemon.

安装器把插件注入桌面端，并注册登录自启的守护进程。

2

Restart the app重启桌面端

A clock appears next to the send button. Sessions and settings stay intact.

发送按钮旁会出现时钟控件，会话与配置不受影响。

3

Uninstall anytime随时卸载

uninstall.ps1 stops the daemon and restores the original bytes.

运行 uninstall.ps1 即可停止守护并还原官方文件。
